Sistema de Biblioteca

Sobre:

Sistema desenvolvido durante a disciplina de Programação Orientada a Objetos (POO) da graduação em Análise e Desenvolvimento de Sistemas.
O projeto tem como objetivo gerenciar uma biblioteca, permitindo o cadastro e gerenciamento de livros, usuários e empréstimos, utilizando Java e MySQL.

---

Tecnologias utilizadas:

- Java
- MySQL
- JDBC
- Git
- GitHub

---

Funcionalidades:

- Cadastro de livros
- Cadastro de usuários
- Empréstimo de livros
- Devolução de livros
- Consulta de registros

---

Estrutura do projeto:

- `connection` – conexão com o banco de dados
- `dao` – acesso aos dados (DAO)
- `db` – configurações do banco
- `docs` – documentação
- `model` – entidades do sistema
- `ui` – interface da aplicação

---

Como executar:

1. Clone este repositório.
2. Configure o banco de dados MySQL.
3. Abra o projeto em uma IDE compatível (IntelliJ IDEA, Eclipse ou NetBeans).
4. Execute a aplicação.
